# Mahalla Pro Android

Android Studio uchun Kotlin + WebView loyihasi. Ilova Mahalla Pro'ning mavjud Render saytini ochadi; interfeys qayta yozilmagan yoki qayta dizayn qilinmagan.

## Ishga tushirish
1. ZIP'ni Extract qiling.
2. Android Studio'da shu `MahallaPro-Android` papkasini oching.
3. Gradle Sync tugashini kuting.
4. Run yoki Build → Build APK(s) ni tanlang.

Talablar: JDK 17, Android SDK 35, internet. Minimal Android 6.0 (API 23).

Sayt manzili: https://mahalla-pro.onrender.com
